# MasterBASIC Decompilation

MasterBASIC is an add-on to SAM BASIC (provided in the submodule SAM ROM - see @ref/samrom),
which extends that BASIC with new commands.

This project exhaustively disassembles and then documents MasterBASIC, and how it works to integrate with the SAM Coupe's existing BASIC ROM
and the MasterDOS disk operating system.
