# Listing Rules

Please assume a maximum listing width of 120 characters, and wrap if necessary.

Where possible within a block, opcodes and inline comments should be aligned with at least one space between the
end of the label definition (:) and the start of the opcode. All opcodes within a block should be aligned at the same
column.

Inline comments after an opcode should all start at the same column within a block wherever possible, with at least a
single space between the last character of an opcode in the block and the start of the comment (;).

Wrapped comments should introduce a new line, with just the comment. Ideally the comment should align with the
line above's comment, but if needed, it could slip left to align to the start of the opcode. It shouldn't
align further left than that.

Section comments should include at least a single blank line above and below them.
