# The last numbers: one to a routine, each explained where it stands.

# Prose for listings/clean/ only.  Anything that needed a paragraph has

# --- 20-bit arithmetic and page form ---------------------------------
DOS &608E : four bits of page above the fourteen-bit offset: 20 bits in all
DOS &6081 : and three for AHLN's nineteen
DOS &4543 : &4000 on: the address moved up a page as the count comes down
DOS &71E1 expr SECTOR_LENGTH-2
DOS &71E1 : 510 bytes a sector, the link excluded
DOS &71E8 : the carry out of the add, into the top byte
DOS &62D4 : C zero, and the INC makes it NZ without touching the flags a compare would
DOS &658F : the fifth byte of the integer form, always zero
DOS &657A expr PAGE_VALUE_MASK
DOS &7B3C : the byte alone

# --- sectors, records and pointers -------------------------------------
DOS &490F expr SECTOR_LENGTH-2
DOS &490F : 510, the data bytes of a sector
DOS &4861 expr SECTOR_LENGTH-2
DOS &4861 : 510, the data bytes of a sector
DOS &711C expr SECTOR_LENGTH-2
DOS &711C : 510 again: the pointer against a sector's data
DOS &7035 expr CNTL
DOS &6FAE : 511 more after the first: the buffer cleared for the next sector
DOS &4FAC : the offset in C alone: GRPNTB takes it in B, POINT gives none
DOS &4829 expr DRIVE-DCHAN
DOS &6F1D : bit 0 is set for OUT, and reading one is "Reading a write file"
DOS &682F expr TYPE_MASK
DOS &68B4 : offset 0, which is &0D only at the end of the list
DOS &68D5 : and its high byte
DOS &7030 : "D", with bit 5 cleared first to fold the case
DOS &67ED : "D"+&80, a temporary channel MOVE made and so one it may reclaim; bit 5 is folded first
DOS &47AD : track 0, sector 1: where a restore leaves the head, and the directory starts
DOS &47CF : 256 turns of the DJNZ, for the controller to settle after a forced interrupt
DOS &47A1 : 150 turns of the delay after a step, for the head to settle
DOS &4A68 : 512: the pointer has reached the end of the buffer

# --- the directory and its entries ------------------------------------
DOS &4B6F : &FF: every sector of the extra track is reserved
DOS &4BBD : &FF is no directory's tag, and means all of them
DOS &55F5 : the directory tracks beyond SAMDOS's four, which is what entry 0 keeps
DOS &4FA7 expr DIR_MODE_NAME_ONLY
DOS &4FA7 : find it by name, whatever its type
DOS &70B6 : 195 bytes of map, eight sectors each: the 1560 sectors after the four directory tracks
DOS &4CFE : 195 bytes of map cleared, eight sectors each: the 1560 after the directory
DOS &4AE0 : the offset in C alone
DOS &4CF1 : "." between a name and its type
DOS &5A03 : offset 11, the file's sector count
DOS &5A98 : forty-two bytes, 210 to 251: the entry's own ten and the ROM header's tail
DOS &4DBC : thirty-three bytes, 15 to 47 of the ROM's header
DOS &6649 : a type of zero is an erased entry
DOS &7898 : the byte alone: the displacement is only eight bits
DOS &5ED3 : track 4: the extended directory skips its first sector, which is why SECTOR_FOR_CHANNEL and the map treat it apart

DOS &7928 : and ")" closes it

DOS &6DD6 : sixteen streams, 0 to 15

DOS &7014 : sixteen streams, 0 to 15

DOS &6A76 : the &FF prefix of a two-byte token: IN and RND are under it, OUT is not

DOS &60C4 : a comma: a directory size follows

DOS &614F expr FIRST_RAMDISC_DRIVE

DOS &7B6A expr FIRST_RAMDISC_DRIVE
DOS &4833 : drive 2's ports are sixteen above drive 1's
DOS &7712 : eighty or more tracks is stored 48 up, so 80 reads as 128 and 160 as 208

# --- the last six ---
DOS &6DFA : zero, which is what a stream above 3 goes back to: no channel
DOS &6DFD expr -(&5C1E+IN_PAGE_C)
DOS &6DFD : minus stream 4's entry in STREAMS, seen through the window: carry below means stream 4 or above
DOS &71D0 expr SECTOR_LENGTH-2

DOS &6CCD : 2 is the mode for RND; the DEC below makes it 1 for OUT
DOS &630A : "." after the "*": only "*." carries on to match extensions
DOS &630E : "." in the target name, where the extension begins
