# Utility pages and SLOTT, under the SAM Technical Manual's own names.

MB &5F14 FIND_SLOTS
MB &5F16 ALLOC_UTILITY_SLOT
MB &5F7B FREE_SLOT_CHAIN
MB &5FA7 FREE_PAGE_IF_SLOTS_CLEAR

MB &5FA7 : SLOTT, the top sixteen bytes of the page, seen in the &8000 window.  It is the same table the allocator keeps clear of -- which is why the topmost slot's link sits sixteen bytes lower than every other slot's

DOC FREE_PAGE_IF_SLOTS_CLEAR
    OR the sixteen SLOTT entries together, and if all are clear write 0
    over the page's ALLOCT byte, giving it back.

    The write goes through WRA, which zeroes HMPR, windows HL up by
    &4000 and puts it back, so the caller needs no paging of its own.

# What the other ALLOCT values mean, from the same page of the manual:
#
#     00H  unused
#     20H  a utilities page
#     40H  used by the first Basic program in the machine
#     60H  used by DOS -- usually just one page
#     C0H  a screen page
#     FFH  non-existent, and one more as a terminator
#
# The table runs 5100H-5120H: thirty-two pages and the terminator.  That
# settles what the installer is doing at &767F, where it puts &60 in
# ALLOCT for its own page -- MasterBASIC is declaring itself a DOS page,
# which is what it is.
#
# What uses it.
#
# The manual describes this pair from the outside without naming it:
# "LPRINT CLEAR 0 has the special function of turning off
# interrupt-driven printing and freeing the buffer space for other
# uses".  FREE_SLOT_CHAIN is reached from &5596, straight after the call
# that loads the print buffer's pointers into V4088 and V4089.  And
# both LPRINT CLEAR and RECORD SOUND are documented as allocating "in 1K
# units", rounded up, which is the slot.
