# SELD works out which drive's port block to use.  &E0 is the disk
# command register nearly everywhere else in the DOS, so these two are
# named here and nowhere else.

DOS &4835 value DISKCTL_0_BASE
DOS &4839 value DISKCTL_1_BASE

# DSC holds the selected drive's base port, which on the WD1772 is the
# command register on write and status on read.  Adding 3 reaches the
# data register.  Every one of these is a LD A,(DSC) followed by a patch
# into an IN, then this, then a patch into another IN.
#
# Rename it in one line if you would rather it were called something
# else: RENAME DISKCTL_DATA_OFS <name>

DOS &4599 value DISKCTL_DATA_OFS
DOS &45CE value DISKCTL_DATA_OFS
DOS &4657 value DISKCTL_DATA_OFS
DOS &4691 value DISKCTL_DATA_OFS
DOS &48C4 value DISKCTL_DATA_OFS
DOS &4A01 value DISKCTL_DATA_OFS
