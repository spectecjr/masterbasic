# Who else uses the ROM's code buffer.

# CDBUFF at &4D00 is not MasterBASIC's.  It belongs to the ROM, which
# copies its own routines into it to run them, and the ROM source says so
# outright: POSFIRST in miscx2.asm does
#
#     LD DE,TOKFIN+3    ;END OF THIS ROUTINE, IN CDBUFF
#
# copying the tokeniser there before running it.
#
# A dump of &4C00-&5BFF from a booted machine settles what is actually in
# it, and the answer is a mixture.  The fourteen bytes at &4D50 match ROM
# 1 at &E049, which is NLTP -- so the ROM had put one of its own ROM 1
# routines there.  The bytes at &4D80 match this half's own &4F14.  And
# &4D18, which BUILD_COMPILER patches with &A8 when it builds, holds &D3, part of
# an OUT instruction belonging to something else.
#
# So the three MasterBASIC builders found earlier -- BUILD_COMPILER at +&11, hook
# 185 at +&50, BUILD_PAGE_IN_TRAMPOLINE also at +&50 -- are not merely
# alternatives to each other.  They are sharing with the ROM.  Whatever
# ran last is what is there, which is why nothing can be assumed about
# the buffer's contents from reading any one builder.
#
# LATER.  Two of the three unexplained things above have an owner, and it
# is a fourth builder: HCMDV's default path, which lays down &CA bytes
# from &4CD3 -- forty-five bytes below CDBUFF -- and is described in
# notes/mb-cmdbuf.txt.
#
#     &4D80 matching this half's &4F14 is that builder's third piece,
#     copied from CMDBUF_EPILOGUE at &4F0C to &4D78.  All thirty-seven
#     bytes match except the two operands it patches.
#
#     &4D18 holding &D3 is the OUT (HMPR),A at &4F76, in the first piece,
#     copied from CMDBUF_PROLOGUE at &4F31 to &4CD3.  It is not part of
#     an instruction belonging to something else; it is the tail of that
#     copy, of which &4CD3-&4CFF and &4D14-&4D1F survive intact and only
#     &4D00-&4D13 -- CDBUFF's own first twenty bytes -- were overwritten.
#
# The fourteen bytes at &4D50 matching ROM 1's NLTP still belong to the
# ROM, so the point above stands: four builders and the ROM share this
# space, and only a dump says what is in it at any moment.
